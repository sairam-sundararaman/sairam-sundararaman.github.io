A randomized mechanism $M$ is $(\varepsilon,\delta)$-differentially private if, for all neighbouring datasets $D, D'$ and every measurable set $S$,

$$
\Pr[M(D) \in S] \le e^{\varepsilon}\,\Pr[M(D') \in S] + \delta .
$$

Calibrating noise to sensitivity is the idea at the core of the definition [@dwork2006calibrating]. Adding $\mathcal{N}(0,\sigma^2 I)$ noise to a query with $\ell_2$-sensitivity $\Delta$ is the standard instance.<Sidenote>This release satisfies $\rho$-zCDP with $\rho = \Delta^2 / 2\sigma^2$ [@bun2016concentrated], and zCDP costs add up across releases.</Sidenote>

## Code

```python
import numpy as np

def gaussian_mechanism(x, sigma, rng=np.random.default_rng()):
    # sigma is the absolute noise standard deviation
    return x + rng.normal(0.0, sigma, size=np.shape(x))
```
